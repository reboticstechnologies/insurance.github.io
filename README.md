# insurance.rebotics.in

Advanced AI-style insurance website for Rebotics.

Includes:
- Home dashboard
- Multi-sector insurance catalogue
- Health, term/life, vehicle, home, travel, business, ULIP/wealth
- Marine, aviation, liability, cyber and agriculture
- International insurance
- AI Advisor prototype
- Claims technology page
- Partner ecosystem
- Contact/enquiry form
- Responsive design
- GitHub Pages compatible

The AI is a front-end prototype. Connect it to a real AI/API, insurer APIs, CRM, quotation engine, KYC, payments and licensed distribution workflow before production.

Regulatory note: insurance availability, advice, solicitation, distribution, underwriting and claims are subject to applicable jurisdictional regulations and insurer terms. For India, production deployment should be reviewed for applicable IRDAI requirements and the exact role/licensing of the business.
